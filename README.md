# Ophia website

The overview site for Ophia, the eye hospital software, written for investors and other stakeholders.

It is a static page: `index.html`, plus screenshots in `assets/shots/` and screen recordings in `assets/video/`. It has no build step and no dependencies.

## View it locally

```bash
python -m http.server 8090
```

Then open http://localhost:8090.

## Hosting

GitHub Pages serves the `main` branch from the repository root. Any push to `main` updates the site.

## About the screens

Every screenshot and video was captured from the real software on 26 October 2026, using demo patients (Arjun P and Shiyas) and test staff accounts. None of it shows real patient data.
